# Tecnologia e Desenvolvimento de Sistemas

Este projeto é uma página web estática desenvolvida com foco na aplicação de boas práticas de desenvolvimento Front-End, organização de código e controle de versão com Git e GitHub.

## 🎯 Objetivo do Projeto
Apresentar de forma clara e estruturada o conceito de Desenvolvimento de Sistemas e introduzir as três principais tecnologias utilizadas na criação de aplicações web modernas (**HTML5**, **CSS3** e **JavaScript**).

## 🛠️ Como foi desenvolvido
* **HTML5 Semântico:** Uso adequado de tags estruturais (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`) para garantir acessibilidade e organização.
* **CSS3 Externo:** Separação total entre estrutura e estilização, utilizando variáveis CSS (`:root`), Flexbox no cabeçalho e CSS Grid para organizar os cards de tecnologias de forma responsiva.
* **Boas Práticas:** Nomenclatura descritiva para classes e IDs em português, indentação padronizada e comentários explicativos nos blocos principais.
